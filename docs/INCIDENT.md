# INCIDENT.md — история сбоев и их причины

## 2026-10-19 — Сайт без стилей на localhost:3010

**Симптомы:** шрифт с засечками, синие ссылки, шапка «продублирована» (мобильное меню видно постоянно), битые картинки.

**Причина:** `@import url(...)` Google Fonts стоял после блока комментариев в `globals.css` — нарушение CSS spec (браузеры игнорируют `@import` после любого не-`@import` контента); параллельно `.mobile-menu` не имел CSS-правила скрытия — без стилей оверлей всегда виден (→ «дублирование шапки»); файл `.next/` содержал кеш от `npm run build` при живом dev-сервере.

**Правило:** `@import` обязан быть **абсолютно первой строкой** в CSS-файле — до комментариев, до `@tailwind`. `npm run build` нельзя запускать при работающем `dev`-сервере.

**Исправление:** перемещён `@import` в самое начало `globals.css`; добавлен `.mobile-menu { transform: translateX(100%); }` + `.mobile-menu.open { transform: translateX(0); }`; удалён `.next/` перед повторным запуском dev.
