# Poliviz Media Assets

Поместите сюда ваши локальные видео и медиафайлы:
- `/media/preloader.mp4` — видео для прелоадера (если файл присутствует, он автоматически включится в прелоадере вместо процедурной графики)
- `/media/press.mp4` — фоновое видео печатного цеха
- `/media/workshop1.mp4` — видео для карточек цехов

Компонент `MediaSwitch.tsx` и `Preloader.tsx` автоматически проверяют наличие файлов в этой папке и бесшовно переключаются с фото Unsplash на живые видео!
